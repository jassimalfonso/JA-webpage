How it works

[03]

  1. Then: Math.random

    Fine for games and shuffling. Not for passwords — it is predictable if someone knows enough about the browser state.

    let randIndex = Math.floor(Math.random() * characters.length);

  2. Now: the browser's crypto

    crypto.getRandomValues draws from the operating system's secure randomness — the same source a password manager uses.

    const buf = new Uint32Array(length); crypto.getRandomValues(buf); const pw = [...buf].map(n => pool[n % pool.length]).join("");

  3. How strong is strong?

    Entropy = length × log₂(pool size). 16 characters from 89 is about 104 bits — far beyond guessing.
