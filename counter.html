Brief

[01]

Count. Save. Forget. Repeat.

A counter for the person on the door: tap for each person, save the batch, and the list of entries builds up underneath.

Fifteen lines of JavaScript. Where variables, functions and the DOM first clicked.

How it works

[03]

  1. A number and a function

    Click runs increment(), which adds one and writes it on the page.

    function increment() { count += 1 countEl.textContent = count }

  2. Save is a reset with a memory

    Save writes the count into the list of entries, then sets it back to zero.

  3. Rebuilt: keys and a total

    Space counts and Enter saves, so you can use it without looking. The entries add up to a total.
