Challenge

[01]

Two teams. Six buttons. One number each.

The brief was simple: a scoreboard you can run from the bench. Tap to add points, reset for the next game.

The first version worked — by writing the same five lines six times. This page is the rebuild.

How it works

[03]

  1. Then: one listener per button

    Every button had its own copy of the same logic. Change one, forget the other five.

    homeAddOneButton.addEventListener("click", function() { homeCount++; homeScoreEl.textContent = homeCount; }); // …and five more just like it

  2. Now: the button says what it does

    Each button carries its team and points in data attributes. One handler reads them.

    <button data-team="home" data-pts="3">+3</button> board.addEventListener("click", (e) => { const b = e.target.closest("button"); score[b.dataset.team] += +b.dataset.pts; render(); });

  3. Extras that came free

    With every play in one place, undo is just popping the last play off a list — and the leading team lights up.
